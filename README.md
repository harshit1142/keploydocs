# Keploy Masterclass: Go + Echo Integration

A high-performance documentation site built with **Next.js 15**, **Tailwind CSS**, and **MDX**. This project serves as a comprehensive technical guide for developers looking to automate testing in Go applications using Keploy's eBPF-based traffic recording.

## Key Features
- **Interactive Documentation**: Leverages MDX to render React components directly within technical tutorials.
- **Dynamic Theming**: Custom-built Dark/Light mode toggle using `next-themes` and Tailwind CSS.
- **Production-Ready UI**: A polished, responsive interface with a focus on developer experience (DX).
- **Deep Technical Guide**: Detailed breakdown of recording and replaying API traffic with Go and PostgreSQL.

## Tech Stack
- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS + @tailwindcss/typography
- **Icons**: Lucide React
- **Content Engine**: @next/mdx
